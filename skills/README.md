# Installed agent skills (local mirror)

Cursor/Codex can load these via `npx skills add <repo>`. This folder vendors the **UI default stack** from the catalog README so agents do not depend on antislop alone.

## UI stack (install)

```bash
npx skills add miqdadbadjuber/anti-slop -g -y
npx skills add nutlope/hallmark -g -y
npx skills add emilkowalski/skills -g -y
npx skills add jakubkrehel/make-interfaces-feel-better -g -y
npx skills add ibelick/ui-skills -g -y
npx skills add nextlevelbuilder/ui-ux-pro-max-skill -g -y
```

## Suggested defaults (from catalog root README)

UI → anti-slop **+** hallmark **+** emil-design-eng **+** make-interfaces **+** ibelick a11y **+** ui-ux-pro-max

Do not treat antislop as the only design skill — it is a filter; craft comes from the rest of the stack.
